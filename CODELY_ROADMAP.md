# Codely product roadmap

Codely is a separate commercial product built on the MIT-licensed bolt.diy foundation. The upstream licence and attribution must remain in the repository and distributions.

## Phase 1 — branded builder foundation

- Codely branding and beginner-friendly prompts
- Keep chat, WebContainer preview, editor, downloads and deployment working
- Verify local production build and select Cloudflare Pages or a compatible container host
- Configure one centrally managed AI provider for the initial launch

## Phase 2 — accounts and durable projects

- Firebase authentication
- Server-owned user profiles and project metadata
- Private project access
- Cross-device project history

## Phase 3 — ₹1,999 subscription and credits

- Razorpay subscription/order verification
- 1,500 monthly credits
- Server-side token metering and atomic credit deductions
- Usage dashboard, limits and top-ups
- Webhook-based renewals, cancellations and payment reconciliation

## Phase 4 — non-coder experience

- Hide model selection, API keys, terminal and source code by default
- Keep Preview, Ask Codely and Publish as the three primary actions
- Guided onboarding and clarification questions
- Plain-language build progress and error recovery

## Phase 5 — launch readiness

- Privacy policy, terms, refund policy and acceptable-use policy
- Rate limits, abuse prevention and secret scanning
- Error monitoring, cost alerts and backups
- End-to-end tests for signup, build, preview, payment and publish
